# The HEX logo in the promo video

`hex-logo.svg` is the HEX mark, embedded in [`../storyboard.html`](../storyboard.html). It's cut from
hex.com's own `/_assets/img/wordmark.svg` (16 November 2026): the same path and gradient, without the
lettering.

PulseChain's and Ethereum's logos are the website's own, in `web/src/assets/chains`. The logos only
show which chains .hex works on: HexNS isn't affiliated with HEX, PulseChain or Ethereum.
