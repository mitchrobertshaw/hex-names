# Logos in the promo video

Copies of the logos the video shows, embedded in [`../storyboard.html`](../storyboard.html). Each
came from its owner's own site or listing on 16 November 2026.

| File | What it is | Where it's from |
| --- | --- | --- |
| `hex-logo.svg` | The HEX mark | Cut from hex.com's own `/_assets/img/wordmark.svg`: the same path and gradient, without the lettering |
| `metamask-fox.svg` | MetaMask's fox | `MetaMask-Logo-Pack.zip`, linked from metamask.io/assets, which comes with MetaMask's brand guidelines |
| `zkx-wallet.jpg` | ZKX Wallet's icon | Its Chrome Web Store listing (offered by LibertySwap Developer), the one LibertySwap's docs link to. There are other "ZKX" projects; this is the wallet. |

PulseChain's and Ethereum's logos are the website's own, in `web/src/assets/chains`. The logos only
show which chains and wallets .hex works with: HexNS isn't affiliated with any of them.
